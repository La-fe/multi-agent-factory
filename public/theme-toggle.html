Theme Toggle Demo

This page demonstrates a smooth dark/light theme toggle with preference persistence via localStorage. Click the button in the top right to switch themes.

How it works

The theme is stored in localStorage so your preference persists across page reloads. CSS custom properties drive all colors, and a CSS transition on each property ensures smooth switching.

No dependencies

This page is a single self-contained HTML file with embedded CSS and JavaScript — no frameworks, no external libraries, no network requests.
